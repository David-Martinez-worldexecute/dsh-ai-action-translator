# Qwen Code（千问） 适配层

> GENERATED by tools/build-adapters.mjs — 不要手改，改 adapters/_core 或 lib/ 后重新生成。

## 它能做什么

- **动作前拦截**：命中 10 条高风险规则时把动作挡在执行之前。
- **提示词**：把 QWEN.md 追加到项目根，让模型按「动作翻译」的格式解释每一步。
- **事后时间线**：可选，默认关。开着的时候每次工具调用会往项目根 `.aiact/timeline.jsonl` 追加一行（工具名 + 参数摘要，敏感键落盘成 `***`）。

## 怎么装

1. 把本目录里的隐藏目录整个复制到你项目的根：
   `cp -r .qwen <你的项目>/`
2. 把 `adapters/_core/` 复制到 `<你的项目>/.aiact/core/`（钩子脚本从这里加载规则）。
3. 把 `QWEN.md.part` 的内容追加到项目根的 `QWEN.md`。
4. 在 `<你的项目>/.aiact/config.json` 里写：

   ```json
   { "mode": "warn", "level": "high", "language": "zh", "audit": false }
   ```

   `mode` 三档：`off`（默认，完全不介入）/ `warn`（放行但提醒）/ `deny`（真的拦）。

   `audit` 是**另一个开关**，默认 `false`。改成 `true` 才会开始记时间线 ——
   守门和记账分开，是因为想回看的人不该被迫先打开拦截，想拦截的人也不该被顺手写一堆日志。
   打开后每次工具调用会往 `.aiact/timeline.jsonl` 追加一行。文件涨到约 128 KB（比 500 行略多）时会裁到最近 500 行。

## 边界（请照着信）

- 证据强度：官方 hooks 文档：POST `{tool_name, tool_input, …}` in，`hookSpecificOutput.permissionDecision` out
- `QWEN.md` 与 `AGENTS.md` 会被自动加载作为项目上下文。
- 官方文档还支持 `type: "http"` 的远程判定服务——本目录**没有**用它：那会把每次工具调用的完整 `tool_input` 发到外部，官方文档自己也提示那是敏感数据。
- 钩子**只认命令的字面特征**，不读文件内容、不做语义判断。它挡的是「明显危险」，不是「所有危险」。
- 钩子脚本自己出错时**一律放行**并把原因写到 stderr：它崩了不该让你所有命令都跑不了。
- 本工具不会修改你的用户级配置（`~/.xxx`），只生成本目录里的项目级文件。
