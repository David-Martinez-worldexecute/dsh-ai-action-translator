# AI 动作翻译器 · 详情

给计算机初学者和学生的 DSH 学习辅助层：**边解释 AI 的动作，边教你 Agent 是怎么跑起来的。**

## 解决什么问题

初学者面对 AI 操作电脑时，最常见的一句是：

> 它到底在干什么？为什么这么做？这串报错是什么意思？

这个插件不改变 AI 做的事，只在它动手前后加一层**人话解释**，并把每个动作放回项目结构里，告诉你它现在在哪一层。

## 它做什么

| 能力 | 说明 |
|---|---|
| 动作翻译 | 工具调用前说清「要做什么、为什么、影响」，返回后说清「实际发生了什么、对下一步意味着什么」 |
| 分级讲解 | `knowledgeLevel` 四档：`plain` 全白话 / `guided` 边做边学 / `balanced` 白话+术语+机制 / `deep` 追调用链 |
| 项目地图 | 固定六层定位：入口/启动点 → 配置与依赖 → 核心模块 → 工具/服务边界 → 输出/界面 → 测试与验证 |
| 阶段小结 | 完成可验证小阶段后，用 2～4 句承接「完成了什么 / 在地图哪层 / 仍未知 / 下一步」 |
| 人物语气 | `persona` 可自定义（≤600 字）；只影响表达，不影响事实与安全边界 |
| 配置预设 | 三档一键切换，不用逐个手调 15 个字段 |
| 配置导出/导入 | 存成 JSON，换电脑或分享给别人 |
| 运行统计 | 看见「观察了多少次工具调用」，确认它真的在工作 |

## 它不做什么

这些是**设计上刻意排除**的，不是还没做：

- 不注册任何工具，不接管工具执行
- 不拦截、不否决、不改写任何工具结果（只用 `tools/result` 这个纯广播事件做只读观察）
- 不联网、不外发任何内容
- 不读写你的项目文件
- 不自动执行动作
- 不声称知道模型的隐藏推理 —— 只解释可观察的事实

## 怎么用

**主入口：DSH 设置页里的「AI 动作翻译器」分区。**

改完保存，下一轮对话自动生效，不用重启 DSH。

分区里还有一个「打开完整页面」按钮，可以打开服务端渲染的完整面板。

> ⚠️ 不要手敲 `/api/ai-action-translator/` 这个地址。`dsh web` 内核把 `/api*` 锁在「启动令牌 → 签名 Cookie」之后，直接访问会先被内核拦下返回 `401 dsh web authentication required`，请求根本到不了插件。这是内核的票据保护，不是插件缺陷。

## 适配范围

**只适用于 DeepSeek Harness（DSH）。** 依赖 DSH 独有 API：`systemPrompt.section()`、`settings.section` 槽位、`~/.dsh/` 数据目录。不能用于其他 Agent 工具。

## 安全边界

- 面板仅应答本机回环（Host 限 `127.0.0.1` / `[::1]` / `localhost`，Origin/Referer 须同源）
- 请求体上限 64KB；未知字段与坏 JSON 返回 400
- 密钥形状字段名主动拦截
- `enabled` / `order` 属结构配置，面板无法修改
- 零网络代码，零运行时依赖
